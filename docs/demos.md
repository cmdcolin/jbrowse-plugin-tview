# Live demos

Each link opens reads from the GIAB Ashkenazi trio (PacBio HiFi, GRCh37,
streamed from GIAB's FTP) in
[JBrowse Web nightly](https://jbrowse.org/code/jb2/main/), with nothing to
install. The reads take a few seconds to appear, because they are fetched by
range request and the alignment is built in a worker.
